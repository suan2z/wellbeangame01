|------|------|
| **가제** | Lane Defense (차선 방어전) |
| **장르** | 캐주얼 슈터 / 하이퍼캐주얼 / 웨이브 디펜스 |
| **플랫폼** | Android (단일) |
| **엔진(예정)** | Unity 6 LTS |
| **타겟 연령** | 10대 후반 ~ 30대 |
| **세션 길이** | 1판 1~3분 |

| **수익화** | 미정 (광고 + IAP 검토 중) |

### 한 줄 소개

> "한 손으로 좌우만 움직여라. 무기는 알아서 쏜다.
> 게이트로 병력을 불리고, 끝없이 몰려오는 적을 막아라."

### 게임 컨셉

YouTube 광고로 유명한 **「Last War: Survival」**의 핵심 메커닉(3레인 자동사격, 게이트 선택, 웨이브 디펜스)을 차용한 캐주얼 슈터. 광고에서만 보던 시원한 손맛을 실제 플레이로 구현하는 것이 목표.

## 2. 컨셉 및 세계관

### 세계관

좀비 바이러스가 퍼진 도시. 플레이어는 생존자 부대를 이끌고 안전구역까지 전진하며 좀비 무리를 처치한다.

### 톤앤매너

- **카툰 스타일**: 진입장벽을 낮추고 잔혹성을 줄여 폭넓은 연령층 흡수
- **시원한 타격감**: 다수의 적을 한꺼번에 처치하는 쾌감 우선
- **유머러스한 좀비**: 무섭기보다 코믹한 디자인

### 아트 레퍼런스

- Last War: Survival
- Stick War
- Archero (캐릭터 비율)

## 3. 핵심 게임플레이

### 코어 루프 (1판 = 1~3분)

```
시작 → 자동 전진 → 좌우 이동(드래그) → 자동 사격
   ↓
게이트 통과 (선택지 효과 적용)
   ↓
웨이브 처치 → 아이템 픽업 → 강해짐
   ↓
보스 처치 → 클리어 → 보상 → 다음 스테이지
```

### 조작

| 입력 | 동작 |
|------|------|
| 화면 좌우 드래그 | 부대 좌우 이동 (3레인) |
| (자동) | 적을 향해 자동 사격 |
| 우하단 버튼(예정) | 액티브 스킬(폭탄, 회복 등) |

**한 손 엄지 조작** 만으로 모든 플레이가 가능해야 함 (지하철·버스 시나리오).

### 게이트 시스템 (핵심 차별화)

부대가 전진하다 만나는 두 갈래 게이트. 어느 쪽으로 통과하느냐에 따라 효과 적용.

#### 게이트 종류

| 타입 | 예시 | 비고 |
|------|------|------|
| **인원 합산** | `+5명` vs `×2배` | 부대원 수 증가 |
| **무기 업그레이드** | `권총 → 기관총` vs `샷건` | 화력 변경 |
| **속성 강화** | `대미지 +20%` vs `사거리 +30%` | 스탯 부스트 |
| **함정** | `+10명` vs `÷2 + 골드` | 위험 감수 선택 |

> 한 판에 게이트는 평균 4~6개. **선택의 즉흥성**이 게임의 맛.

### 적/웨이브 구성

| 적 타입 | 특징 |
|---------|------|
| 일반 좀비 | 느림, 약함, 다수 |
| 러너 좀비 | 빠름, 약함 |
| 탱커 좀비 | 느림, 강함 |
| 자폭 좀비 | 빠름 + 부대원 수 -1 |
| **보스** | 스테이지 끝, 패턴 보유 |

웨이브는 점진적으로 강도 상승: 일반 → 혼합 → 미니보스 → 게이트 → 반복 → 최종 보스

### 진행 / 실패 조건

- **클리어**: 보스 처치 + 부대원 1명 이상 생존
- **실패**: 부대원 전원 사망

## 4. 콘텐츠 구성

### 캐릭터 / 부대원

| 분류 | 예시 |
|------|------|
| 기본 군인 | 권총/기관총 |
| 메딕 | 부대 체력 회복 |
| 저격수 | 원거리 고대미지 |
| 화염병 투척병 | 광역 공격 |
| 방패병 | 전열 방어 |

### 무기

권총 → 기관총 → 샷건 → 라이플 → 로켓런처 → 레이저 (게이트로 단계 변화)

### 아이템 (필드 픽업)

| 아이템 | 효과 |
|--------|------|
| 골드 코인 | 스테이지 후 영구 업그레이드 재화 |
| 보호막 | 일정 시간 무적 |
| 폭탄 | 화면 내 적 일소 |
| 자석 | 코인 자동 흡수 |

### 스테이지 구조

- **챕터제**: 1챕터당 10스테이지 + 챕터 보스
- **테마**: 시내 → 군사기지 → 지하터널 → 해변 → 우주정거장
- **출시 목표**: 챕터 5개 (총 50+ 스테이지)
- **무한 모드**: 챕터 외 별도 모드, 영구 업그레이드용 골드 파밍

### 메타 진행 (영구 업그레이드)

스테이지 클리어로 얻은 골드로 메인 메뉴에서 영구 강화:

- 시작 부대원 수 +N
- 기본 대미지 +%
- 사거리 +%
- 골드 획득량 +%
- 추가 슬롯/스킬 해금

> 메타 진행이 **"한 판 더!"**의 동력.

## 5. UI / UX

### 메인 화면

```
┌──────────────────────────┐
│  [상단] 골드/보석 표시      │
│                          │
│   [캐릭터 일러스트]        │
│                          │
│   ▶ 시작 (현재 스테이지)    │
│   ⚙ 업그레이드             │
│   🏆 무한 모드             │
│   📜 도감                 │
│                          │
│  [하단] 일일 미션 / 설정    │
└──────────────────────────┘
```

### 인게임 HUD

- **상단**: 진행도 바, 일시정지
- **중앙**: 게임 화면 (3레인)
- **하단 좌측**: 부대원 수 / 무기 단계
- **하단 우측**: 액티브 스킬 (예정)

### 결과 화면

- 클리어 / 실패
- 획득 골드, 처치 수, 진행도
- **광고 보고 보상 2배** 버튼
- 다음 스테이지 / 메뉴 / 재시도

### 튜토리얼

첫 3스테이지에 걸쳐 분할 학습:
1. 좌우 드래그로 이동
2. 게이트 선택
3. 보스전 + 결과 화면

## 6. 기술 스택 (예정)

| 영역 | 후보 |
|------|------|
| **엔진** | Unity 6 LTS |
| **언어** | C# |
| **렌더링** | URP (Universal Render Pipeline) |
| **물리** | 2D 또는 3D-탑다운 (논의 필요) |
| **로컬 저장** | PlayerPrefs (간단) + JSON 백업 |
| **광고 SDK** | Google AdMob |
| **IAP** | Unity IAP |
| **분석** | (오프라인이지만) Firebase Analytics 검토 |
| **아트** | 카툰 셰이더, 무료 에셋 + 외주 검토 |

### 오프라인 설계 원칙

- 모든 게임 로직 클라이언트 처리
- 결제만 IAP 영수증 검증 (Google Play 측)
- **세이브 데이터 보호**: PlayerPrefs는 평문이라 변조 가능 → JSON + 간단 해시 검증
- **시간 조작 방지**: 일일 보상은 디바이스 시간 변화 감지 (오프라인 한계 인정)

| 위치 | 형태 | 빈도 |
|------|------|------|

### IAP

| 상품 | 가격(예시) |
|------|-----------|
| 광고 제거 | ₩4,400 |
| 골드 패키지 (소/중/대) | ₩1,500~₩33,000 |

## 8. 개발 일정 (안)

| 단계 | 기간 | 주요 산출물 |
|------|------|-------------|
| **기획 확정** | 1주 | 기획서 v1.0, 와이어프레임 |
| **프로토타입** | 2주 | 1레인 이동 + 자동사격 + 게이트 1종 |
| **알파** | 4주 | 5스테이지, 게이트 4종, 메타 업그레이드 |
| **베타 (CBT)** | 4주 | 챕터 1~2 완성, 광고/IAP 연동, 밸런싱 |
| **출시 준비** | 2주 | 스토어 등록(Play Console), QA, 마케팅 자산 |
| **총** | **약 13주 (3개월)** | 1인 개발 가정 |

### 마일스톤별 검증 지표

- 프로토타입: 코어 루프 재미 검증 (자체 플레이 30판)
- 알파: 친구 5명 플레이 → 평균 세션 2판 이상
- 베타: CBT 100명 → D1 리텐션 ≥ 30%

## 9. 리스크 및 이슈

| 리스크 | 영향 | 대응 방안 |
|--------|------|-----------|
| **표절 시비** (Last War 유사) | 출시 차단 | 메커닉만 차용, 비주얼/IP는 독자 디자인 / 사명·캐릭터 차별화 |
| **성능 이슈** (적 다수 + 총알 다수) | 저사양 폰에서 프레임 드랍 | 오브젝트 풀링, GPU 인스턴싱 |
| **단조로움** | 이탈률 증가 | 챕터마다 신규 게이트/적/메커닉 도입 |
| **세이브 변조** | 인앱 매출 손실 | 간단 해시 검증, 핵심 진행은 영수증으로 잠금 |
| **광고 SDK 정책** | 매출 정지 | AdMob 정책 정독, 보상형 광고 빈도 제한 |
| **앱 용량** | 다운로드 이탈 | 에셋 압축, 초기 다운 < 100MB 목표 |

## 10. 차별화 요소 / 향후 검토

- **반려 시스템**: 강아지/로봇 펫이 따라다니며 추가 사격

- **시즌 이벤트**: 핼러윈/크리스마스 스킨
- **협동 모드**: (서버 없음 가정에서) 비동기 친구 점수 비교만
