|------|------|

### 한 줄 소개

> "게이트를 골라 부대를 불리고, 콤보로 화력을 끌어올려라.
> 위기엔 에어스트라이크 한 방. 끝없이 몰려오는 적을 쓸어담아라."

### 콘셉트

전작 **Lane Defense**의 자동사격 + 무기 상자 손맛을 계승하되, 전작에서 *컨셉만 있고 미구현*이던 **게이트 시스템**을 핵심으로 끌어올리고, 단조롭던 적 구성을 **4종**으로 늘렸다. 여기에 **콤보 · 에어스트라이크 · 코인**을 더해 "쓸어담는 쾌감"과 "순간 선택의 긴장"을 동시에 잡는 것이 목표.

## 2. 핵심 게임플레이

### 코어 루프

```
시작 → 좌우 드래그 이동 → 자동 사격 (콤보 누적)
   ↓
게이트 한 쌍 강하 → 좌/우 선택 통과 (부대 ×2 / +N / 무기UP / 버프)
   ↓
적 4종 + 무기상자 + 코인 처리, 위기 시 에어스트라이크(💥)
   ↓
웨이브 보스(7종 탄막) 처치 → 다음 웨이브
   ↓ (스테이지당 웨이브 = 3 + 스테이지)
스테이지 클리어(보너스) → 부대·무기 계승 → 다음 스테이지(무한, 적·보스 HP 상승)
   ↓
부대원 전멸 → 게임오버 → 하이스코어 저장 → 재시작
```

### 조작

| 입력 | 동작 |
|------|------|
| 화면 좌우 드래그 | 부대 좌우 이동 |
| (자동) | 적을 향해 자동 사격 |
| 우하단 💥 버튼 | 에어스트라이크 (충전 완료 시) |
| 좌하단 텍스트 | 소리 ON/OFF |

**한 손 엄지 조작**으로 이동·게이트 선택·스킬까지 가능하도록 설계.

## 3. 신규/강화 시스템

### 3-1. 게이트 시스템 (핵심 차별화)

- **13초마다** 전투 구역을 좌/우 두 패널로 가르는 게이트 한 쌍이 강하.
- 부대 중심이 **부대원 라인(Y)**에 닿는 순간, 부대가 **왼쪽/오른쪽 어디에 있느냐**로 효과가 결정된다.
- 효과는 **부대 계열(초록)** 과 **화력 계열(파랑)** 로 나뉘며, 70% 확률로 서로 다른 계열 한 쌍이 제시되어 "성장 vs 화력"의 선택을 만든다.

| 계열 | 효과 예시 |
|------|----------|
| 부대(초록) | `×2` · `×1.5` · `+10~25명` |
| 화력(파랑) | `무기 UP`(등급+1) · `DMG +30%` · `연사 +20%` · `탄환 +1` |

> 최고 등급에서 `무기 UP`을 고르면 데미지 +20%로 환산된다.

### 3-2. 적 4종

| 적 | 색 | 특징 | 등장 |
|----|----|------|------|
| **Normal** | 핑크 | 기본, 표준 속도 | S1~ |
| **Runner** | 노랑 | 작고 매우 빠름, 체력 낮음 | S1~ |
| **Swarm** | 초록 | 4~7마리 군집 스폰 | S2~ |
| **Zigzag** | 하늘 | 사인파 좌우 이동으로 회피 | S2~ |
| **Tanker** | 보라 | 크고 느림, 고체력(체력바 표시), 코인 다량 | S3~ |

> 모든 적 HP는 스테이지 비례(`×(1 + (stage-1)×0.35)`)로 상승.

### 3-3. 콤보 시스템

- 적 처치마다 콤보 +1, **2.6초** 내 다음 처치가 없으면 리셋.
- **피격(부대원 손실) 시 즉시 0**으로 리셋 → 무피해 플레이 유도.
- 점수 배수 = `1 + min(combo, 60) × 0.04` (**최대 약 3.4배**). 3콤보부터 화면에 `COMBO N xM.M` 표시.

### 3-4. 에어스트라이크 (액티브 스킬)

- 우하단 💥 버튼. **14초** 쿨다운(원형 게이지로 충전 표시), **게임 시작 시 1회 충전 완료**.
- 발동 시 폭탄 **7발**이 시차를 두고 낙하 → 착탄 지점 반경 95px **일반 적 전멸 + 코인/점수 획득**, **보스에는 최대 HP의 12%×피격수** 피해.
- 화면 흔들림 + 연쇄 폭발 파티클 + 전용 사운드.

### 3-5. 코인

- 적 처치 시 종류별 코인 드롭(러너 1, 탱커 4, 보스 14 등).
- 잠깐 튄 뒤 **부대 중심으로 자석 흡수**, 획득 시 점수 +2 & 코인 카운트 증가.
- (향후) 코인으로 판 간 영구 업그레이드 연동 검토.

### 3-6. 스테이지 계승

전작은 스테이지 클리어 시 부대·무기를 초기화했지만, v2는 **부대원과 무기를 계승**해 파워 판타지를 강화한다. 대신 **적·보스 HP가 스테이지 비례로 상승**해 난이도 곡선을 유지하고, 클리어 시 `200 × 스테이지` 보너스 점수를 준다.

## 4. 콘텐츠 / 밸런스 요약

| 항목 | 값 |
|------|----|
| 시작 부대원 | 3명 |

| 보스 탄막 | 7종 순환 (조준/3·5-way/점사/전방위/나선/벽-틈새) |
| 게이트 간격 / 강하 속도 | 13초 / 70px·s |
| 에어스트라이크 | 14초 충전, 폭탄 7발, 반경 95px |
| 콤보 윈도우 / 최대 배수 | 2.6초 / 약 3.4배 |

## 5. 기술 스택

| 영역 | 사용 기술 |
|------|----------|
| **엔진** | Phaser 3 (Arcade Physics) |
| **언어** | JavaScript (ESM) |
| **번들러** | Vite |
| **렌더링** | WebGL/Canvas, 텍스처는 **런타임 Graphics 생성** (이미지 에셋 0) |
| **사운드** | Web Audio API 합성 (에셋 파일 0) |
| **로컬 저장** | `localStorage` (하이스코어 · 음소거) |
| **배포** | GitHub Actions → GitHub Pages (`/play2`) + MkDocs 문서 |

### 코드 구조 (`game2/`)

```
game2/
  index.html
  src/
    main.js              # Phaser 부트스트랩 (540×960, FIT)
    sfx.js               # Web Audio 합성 효과음 (+게이트/콤보/코인/폭격)
    scenes/GameScene.js  # 게임 로직 전체 (텍스처 생성 포함)
```

> 전작 `game/`(→ `/play`)과 완전히 분리된 독립 빌드. 공통 인프라(MkDocs/Vite/Pages)만 공유.
