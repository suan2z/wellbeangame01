## 현재 상태

플레이 가능한 프로토타입 **v0.1**. Phaser 3 웹 빌드(`game2/` → `/play2`), GitHub Pages 자동 배포.

전작 Lane Defense(`game/` → `/play`)를 기반으로 **"비슷하지만 더 재밌게"** 재구성한 후속작. 코드는 전작에서 포크해 시작했으나 독립 빌드로 분리되어 있다.

### 이번에 새로 넣은 것 (v1 → v2)

- **게이트 시스템** — v1에서 컨셉만 있던 핵심 기능을 실제 구현 (좌/우 선택 통과)
- **적 4종** — 러너 · 스웜(군집) · 지그재그 · 탱커 (v1은 Normal 1종)
- **콤보 시스템** — 연속 처치 점수 배수 (피격 시 리셋)
- **에어스트라이크** — 우하단 충전식 액티브 스킬 (폭탄 연쇄)
- **코인** — 적 처치 드롭 + 자석 흡수
- **스테이지 계승** — v1의 부대/무기 초기화 대신 계승(파워 판타지), 적·보스 HP는 비례 상승
- **보스 탄막 +2종** — 나선 · 벽-틈새

상세는 [개요](index.md) · [기획서](기획서.md).

## 주요 결정 (왜 그렇게 했는지)

| 결정 | 이유 |
|------|------|
| **별도 디렉터리 `game2/`** | 전작을 보존하면서 독립 배포(`/play2`). 인프라만 공유 |
| **게이트 = 좌/우 선택식** | 모바일 한 손 조작에 가장 직관적. 사격 강화식은 후속 검토 |
| 게이트 효과 **70% 이종 페어** | "성장 vs 화력"의 선택 긴장을 자주 만들기 위해 |
| **스테이지 계승**(부대·무기 유지) | v1의 리셋은 로그라이크 지향. v2는 "쓸어담는 쾌감"=파워 판타지로 차별화 |
| 적 HP **스테이지 비례 상승** | 계승으로 강해지는 부대와 균형 맞춤 |
| **콤보 리셋 = 피격 시** | 무피해 플레이 보상 → 회피 동기 강화 |
| **에어스트라이크 시작 시 충전** | 첫 위기에 바로 손맛, 튜토리얼 없이도 발견 유도 |
| 코인 **자석 흡수** | 일일이 줍는 번거로움 제거, 시원한 수거감 |
| 사운드 = **Web Audio 합성** | 전작과 동일, 에셋 0·오프라인 동작 |

## 빌드 / 실행

```bash
cd game2
npm install
npm run dev      # 로컬 개발 (http://localhost:5174)
npm run build    # dist/ 생성 → 배포 시 site/play2 로 복사
```

배포는 `.github/workflows/deploy-docs.yml`이 `main` push 시 `game2`를 빌드해 `site/play2/`로 합친다.
