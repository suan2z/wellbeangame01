## 🆕 v1 대비 달라진 점

| 영역 | Lane Defense (1) | **Lane Defense 2** |
|------|------------------|--------------------|
| **성장 방식** | 무기 상자 + 부대원 아이템 | **게이트 선택**(×2 / +N / 무기UP / 버프) 추가 |
| **적 종류** | Normal 1종 | **4종**: 러너 · 스웜(군집) · 지그재그 · 탱커 |
| **점수 연출** | 단순 가산 | **콤보 배수**(연속 처치 시 최대 ~3.4배) |
| **액티브 스킬** | 없음 | **에어스트라이크**(쿨다운 충전식 폭격) |
| **재화** | 없음 | **코인** 드롭 + 자석 흡수 |
| **스테이지 계승** | 클리어 시 부대·무기 초기화 | **부대·무기 계승**(파워 판타지 강화) |
| **보스 탄막** | 5종 | **7종**(나선 · 벽-틈새 추가) |

## 📌 진행 상태

!!! success "현재 단계"

### 구현 완료 ✅

- 좌우 드래그 이동 + 전 부대원 자동 사격 (해바라기 원형 분포)
- **게이트 시스템** — 13초마다 한 쌍 강하, 좌/우로 통과해 효과 선택
- **적 4종** — 러너(고속) · 스웜(군집) · 지그재그(사인 이동) · 탱커(고체력·체력바)
- **콤보 시스템** — 연속 처치로 점수 배수 상승, 피격 시 리셋
- **에어스트라이크** — 우하단 버튼, 14초 충전, 폭탄 7발 연쇄 폭격 (보스에 12%×n 피해)
- **코인** — 적 처치 시 드롭, 부대로 자석 흡수, 점수·코인 카운트
- 무기 **10종 (T1~T10)** + 등급별 부대원 외형 + 무기 상자(3레인 낙하)
- 부대원 아이템 -1/+1/+2/?(좌우 낙하)
- **스테이지 무한 + 부대·무기 계승**(적·보스 HP는 스테이지 비례 상승)
- 보스 5종 외형 순환 + **7종 탄막**(조준/3·5-way/점사/전방위/나선/벽-틈새)
- 스테이지별 배경 팔레트 + 처치 파티클 / 화면 흔들림
- 음향 효과 (Web Audio API, 에셋 파일 없음) + 게이트/콤보/코인/폭격 전용 사운드
- 하이스코어 로컬 저장
