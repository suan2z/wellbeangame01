## 현재 상태

**프로토타입 v0.1.** Three.js + Vite, `/meteor/` 경로로 자동 배포 중.

코어 루프 동작: 도시 한복판에 캐릭터 → 가상 조이스틱으로 4/360° 이동 → 카메라 추적 → 운석이 하늘에서 그림자 예고 후 낙하 → 1히트 게임오버 → 다시하기.

비주얼은 절차적 박스/구체 + 단색 (Lane Defense와 같은 방식, 에셋 파일 0).

## 주요 결정 (왜 그렇게 했는지)

| 결정 | 이유 |
|------|------|
| 엔진 = **Three.js + Vite** | Phaser는 2D 전용, Three.js가 웹 3D 표준. Lane Defense와 같은 빌드 흐름 |
| 그래픽 = **절차적 도형 + 단색** | 모델 파일 없이 시작, 동작 검증 우선 (Lane Defense에서 검증된 방식) |
| 이동 = **가상 조이스틱 360°** | 사용자 요청 (`화면 하단의 조이패드`). 화면 좌하단 + 좌측 절반 어디 터치해도 발동 |
| 카메라 = **3인칭 추적** (캐릭터 약간 뒤·위) | 사용자 요청 (`카메라가 캐릭터를 따라다님`) |
| 캐릭터 = **화면 중앙 하단 고정** | 사용자 요청. 카메라가 캐릭터에 lerp 추종해서 결과적으로 그렇게 보임 |
| 운석 = **그림자 예고 0.9초** | 회피 게임 정석. 갑자기 떨어지면 운에 가까움 |
| 도시 = **링 형태 빌딩 200개** | 안쪽은 비워 전투공간 확보, 바깥은 배경 채움 |
| 충돌 = **1히트 게임오버** | 아케이드 회피 정석. HP 시스템은 추후 검토 |
| 점수 = **생존 시간** | 가장 간단한 회피 게임 정석 |

## 코드 구조

```
meteor-game/
├── index.html
├── vite.config.js          base './' → /meteor/ 어느 경로든 작동
├── src/
│   ├── main.js             게임 부팅 + window.__meteorGame 디버그 훅
│   ├── game.js             씬·카메라·라이팅·루프
│   ├── scenes/city.js      절차적 도시 빌딩
│   ├── objects/player.js   캐릭터 (이동/턴/경기장 클램프)
│   ├── systems/camera.js   ChaseCamera (lerp 추종)
│   ├── systems/meteors.js  풀링 + 그림자 예고 + 스폰 간격 곡선
│   └── ui/
│       ├── joystick.js     가상 조이스틱 (드래그 360°)
│       └── hud.js          TIME/SCORE + 게임오버 화면
```

워크플로우(`deploy-docs.yml`)가 자동으로 `meteor-game/`을 빌드해 `/meteor/`로 배포.
