## 현재 상태

**프로토타입 v0.2.** Three.js + Vite, `/meteor/` 경로로 자동 배포 중.

코어 루프 + **이펙트/애니메이션/사운드까지** 동작:

- 도시 한복판에 캐릭터 → 가상 조이스틱으로 360° 이동
- 카메라 추적 (높이 4 / 시점 3.5 / FOV 75° — 거의 수평 시점, 캐릭터 화면 중상단 + 하늘 넓게 가시화)
- 운석 진입 (y=40) → 1.2초 그림자 예고 → 낙하 → **지면 폭발 이펙트** (파편 + 충격파 링 + 섬광 + 잔류 크레이터)
- **운석 4티어** (small r0.7~1.0 / medium r1.8~2.5 / large r3.5~5.0 / huge r7.0~10.0 — 가중 50/27/16/7%), 큰 운석은 살짝 느리게 낙하 + 폭발 반경 ↑
- **대각선 낙하 궤도** (slope 0.5, 약 27°): 화면 뒤쪽 −Z에서 시작해 카메라 쪽 +Z 방향으로 다가오며 떨어짐 → 운석이 더 잘 보임
- **2~3초마다 캐릭터 위치 조준 운석** 추가 스폰 (`spawnAimed`) — 1.2초 텔레그래프 동안 회피 필요
- **60초 이후 살보 폭격**: 8~12초마다 캐릭터 주변 원형으로 small/medium 6발 동시 낙하 (1.5초 텔레그래프)
- **점프 버튼** (왼쪽 하단 조이스틱 위쪽): facing 방향으로 약 6m 대시(0.32s, 속도 선형 감쇠) + 1초 쿨타임 + 원형 파이 sweep 잔여 시간 시각화
- 캐릭터 **절차 애니메이션** (이동 시 다리/팔 스윙·앞 기울임·바운스, 대기 시 호흡)
- **Web Audio 사운드** (경고/휘파람/폭발/발걸음/게임오버/UI) + 음소거 토글
- 1히트 게임오버 → 즉시 폭발 + 게임오버 사운드 + 다시하기

비주얼은 절차적 박스/구체 + 단색 (Lane Defense와 같은 방식, 에셋 파일 0).

## 주요 결정 (왜 그렇게 했는지)

| 결정 | 이유 |
|------|------|
| 엔진 = **Three.js + Vite** | Phaser는 2D 전용. Lane Defense와 같은 빌드 흐름 |
| 그래픽 = **절차적 도형 + 단색** | 모델 파일 없이 시작, 동작 검증 우선 |
| 이동 = **가상 조이스틱 360°** | 사용자 요청 (`화면 하단의 조이패드`). 좌측 절반 어디 터치해도 발동 |
| 카메라 = **3인칭 추적** + 높은 시점 | 사용자 요청 (`카메라 각도를 높여서 운석 보이게`) |
| 캐릭터 = **화면 중앙 하단 고정** | 카메라가 lerp 추종해서 결과적으로 그렇게 보임 |
| 운석 = **그림자 예고 1.2초** | 진입 높이 낮춤 보정 + 회피 게임 정석 |
| 도시 = **링 형태 빌딩 200개** | 안쪽은 비워 전투공간 확보 |
| 충돌 = **1히트 게임오버** | 아케이드 회피 정석. HP 시스템은 추후 검토 |
| 캐릭터 모션 = **절차 애니메이션** | 모델/스켈레톤 없이도 자연스러운 움직임 가능. sin파 기반 다리/팔 스윙 |
| 폭발 = **파편 + 링 + 섬광 + 크레이터 풀** | Three.js에 내장 파티클 없음 → 메쉬 풀 + 수동 업데이트 |
| 사운드 = **Web Audio 합성** | Lane Defense의 `sfx.js` 패턴 재사용. 에셋 파일 0 |

## 코드 구조

```
meteor-game/
├── index.html
├── vite.config.js          base './' → /meteor/ 어느 경로든 작동
├── src/
│   ├── main.js             게임 부팅 + window.__meteorGame 디버그 훅
│   ├── game.js             씬·카메라·라이팅·루프·콜백 와이어링
│   ├── sfx.js              Web Audio 합성 + 음소거 영속화
│   ├── scenes/city.js      절차적 도시 빌딩
│   ├── objects/player.js   토르소+머리+다리×2+팔×2, 절차 애니메이션
│   ├── systems/camera.js   ChaseCamera (lerp 추종)
│   ├── systems/meteors.js  풀링 + 그림자 예고 + onImpact 콜백
│   ├── systems/effects.js  폭발 파편/링/섬광/크레이터 풀
│   └── ui/
│       ├── joystick.js     가상 조이스틱 (드래그 360°, 첫 터치 시 sfx.resume)
│       └── hud.js          TIME/SCORE + 음소거 토글 + 게임오버 화면
```

워크플로우(`deploy-docs.yml`)가 자동으로 `meteor-game/`을 빌드해 `/meteor/`로 배포.
