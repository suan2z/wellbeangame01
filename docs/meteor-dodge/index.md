### 구현 완료 ✅

- 절차적 도시 (박스 빌딩 200개 링 형태 배치)
- 3인칭 추적 카메라 (높이 4, 시점 3.5 위쪽, FOV 75° — 거의 수평, 하늘 넓게 가시)
- 가상 조이스틱 (화면 좌하단, 드래그 360°)
- **캐릭터 절차 애니메이션**: 토르소 + 머리 + 양다리 + 양팔, 이동 시 다리/팔 스윙·앞으로 기울임·상하 바운스, 대기 시 호흡
- 운석 풀링 (48개) — **4티어 사이즈** (small r0.7~1.0 / medium r1.8~2.5 / large r3.5~5.0 / huge r7.0~10.0, 가중 50/27/16/7%), 정점 jitter로 불규칙 형태, 진입 높이 40
- **그림자 예고**: 운석 낙하 1.2초 전 지면에 빨강 원 표식
- **폭발 이펙트** (지면 임팩트 시):
    - 12+ 파편 입자 (3색 — 노랑/주황/갈색, 중력·바운스)
    - 확장 충격파 링 (3색 잔광)
    - 섬광 (sphere, 0.18초)
    - 잔류 크레이터 (4초 페이드)
- **사운드** (Web Audio 합성, 에셋 0): 경고음 / 휘파람(낙하 시작) / 폭발(임팩트) / 발걸음 / 게임오버 / UI 클릭, **음소거 토글** (localStorage 저장)
- 충돌 1히트 게임오버 + 즉시 폭발 + 사운드
- 시간 카운터 + 점수 (10pt/sec)
- 게임오버 화면 + 다시하기
