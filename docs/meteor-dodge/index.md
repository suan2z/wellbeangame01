# 운석피하기 (Meteor Dodge)

> 도시에 서있는 캐릭터를 조종해 하늘에서 떨어지는 운석을 피하는 3인칭 3D 캐주얼 회피 게임.  
> Three.js + Vite · 오프라인 싱글.

## 진행 상태

!!! info "현재 단계"
    **프로토타입 v0.1** — 코어 루프 동작 (도시·캐릭터·카메라 추적·조이스틱·운석 강하·충돌·시간 카운터·게임오버).
    그래픽은 절차적 도형 + 단색으로 시작 (Lane Defense와 같은 방식).

### 구현 완료 ✅

- 절차적 도시 (박스 빌딩 200개 링 형태 배치)
- 3인칭 추적 카메라 (캐릭터 약간 뒤·위쪽)
- 가상 조이스틱 (화면 좌하단, 드래그 360°)
- 캐릭터 캡슐 + 머리 + 방향 표식 + 발 밑 링
- 운석 풀링 (48개), IcosahedronGeometry + 정점 jitter (불규칙 형태)
- **그림자 예고**: 운석 낙하 0.9초 전 지면에 빨강 원 표식
- 충돌 1히트 게임오버
- 시간 카운터 + 점수 (10pt/sec)
- 게임오버 화면 + 다시하기
