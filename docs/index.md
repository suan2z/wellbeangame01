### 구현 완료 ✅

- 좌우 드래그 이동 + 자동 사격
- 일반 적 웨이브 (60ms 간격)
- 보스 5단계 순차 등장 + 단계별 탄막 패턴
- 보스 라운드 시스템 (5보스 격파 후 HP ×1.5 반복)
- 보스 처치 시 강화 선택 (6종 중 3개 제시)
- 무기 5종 + 무기 상자 시스템 (중앙 3레인 낙하)
- 부대원 아이템 -1/+1/+2/? (좌우 랜덤 낙하)
- 음향 효과 (Web Audio API, 에셋 파일 없음)
- 하이스코어 로컬 저장
