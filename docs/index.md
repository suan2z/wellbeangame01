## 사용 방법

이 사이트는 [MkDocs](https://www.mkdocs.org/) + [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) 로 만들어졌습니다.

### 로컬에서 미리보기

```bash
pip install mkdocs mkdocs-material
mkdocs serve
```

브라우저에서 [http://localhost:8000](http://localhost:8000) 접속.

### 정적 사이트 빌드

```bash
mkdocs build
```

`site/` 폴더에 결과물이 생성됩니다.
