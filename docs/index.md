# 게임 라이브러리

여러 모바일 게임 프로토타입의 기획 문서와 빌드 산출물을 한곳에서 관리합니다.

🕒 **최종 빌드:** `BUILD_TIMESTAMP`

---

## 게임 목록

| 게임 | 장르 | 상태 | 한 줄 요약 | 문서 |
|------|------|------|----------|------|
| **Lane Defense** | 캐주얼 슈터 · 라스트워 류 | 🟢 v0.3 플레이 가능 | 무한 스테이지 + 무기 10종 + 보스 탄막 + 강화 선택 | [개요](lane-defense/index.md) · [📜 히스토리](lane-defense/히스토리.md) · [🎮 플레이](play/) |
| **운석피하기** | 캐주얼 회피 | ⚪ 컨셉 단계 | 세부 기획 협의 전 | [개요](meteor-dodge/index.md) · [📜 히스토리](meteor-dodge/히스토리.md) |

> 💡 **다른 PC/세션에서 작업 이어가실 때**는 해당 게임의 **작업 히스토리** 페이지를 먼저 읽으면 컨텍스트가 빠르게 복원됩니다.

---

## 사이트 구조

- **상단 탭** 으로 게임을 전환합니다.
- 각 게임 탭의 **좌측 사이드바**에서 개별 문서를 탐색합니다.
- 새 게임을 추가하려면 `docs/<게임명>/` 폴더와 `mkdocs.yml` nav에 항목을 추가하면 됩니다.
