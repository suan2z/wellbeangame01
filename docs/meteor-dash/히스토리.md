## 현재 상태

**프로토타입 v0.2.** Three.js + Vite, `/meteor2/` 경로로 자동 배포.

운석피하기1(`meteor-game/`)을 **거의 그대로** 가져오고(동일 카메라·직접 이동·점프·회피 운석), **맵만 일직선 길**로 바꾼 뒤 **거대 운석 붕괴** 메커니즘을 얹었다.

- 운석피하기1과 동일: 가상 조이스틱 **직접 360° 이동**, 낮은 추적 카메라(높이 4), 점프 회피 대시, 그림자 예고 + 대각선 낙하 회피 운석, 1히트 게임오버, 절차 애니메이션, Web Audio 사운드
- 맵: **일직선 길 + 좌우 도시** (길 폭 30, 화면보다 살짝 넓게). 구획 18개를 플레이어 주변에 유지·재활용 → 끝없는 길
- **거대 운석 5초마다**: 길 전방(-Z)에 길 전체 폭으로 강타 → 대폭발 + 화면 흔들림
- **붕괴**: `collapseZ`보다 안쪽(-Z)은 무너진 길(어둡게 가라앉은 잔해, **불 연출 없음**). 거대 운석 착지 때 경계가 점프하고 평상시에도 creep으로 전진. `playerZ <= collapseZ`면 게임오버 → 앞이 막혀 카메라 쪽으로 후퇴 유도

> ⚠️ **이전 v0.1(엔드리스 러너 + 화염벽) 설계는 폐기됨.** 사용자 피드백: "불타는 연출 ❌, 자동 달리기 ❌, 운석피하기1과 동일한 카메라·직접 이동 ✅". destruction.js(화염벽) 삭제, camera/player를 1과 동일하게 복구.

## 주요 결정 (왜 그렇게 했는지)

| 결정 | 이유 |
|------|------|
| **운석피하기1을 베이스로 복제** | 사용자 요청 "기본적으로 1과 동일한 카메라/구도, 직접 이동". camera.js·player.js·meteors(회피)·effects·hud를 1에서 가져옴 |
| 좌표계/카메라 = **1과 동일** (뒤 +Z·높이 4에서 -Z를 봄) | 화면 안쪽(-Z)=전방, 카메라 쪽(+Z)=뒤쪽. 거대 운석은 전방(-Z)에 떨어짐 |
| 이동 = **직접 360° 조이스틱** (자동 달리기 제거) | 이전 러너 설계가 의도와 전혀 달랐음. 자유 이동이되 앞이 막혀 자연히 후퇴 |
| 맵 = **일직선 길 + 좌우 도시**, 폭 30 | "1직선 길, 좌우 도시, 화면보다 살짝 넓게" 요청. 구획 재활용으로 끝없이 |
| 거대 운석 = **길 전체 폭(반지름 ROAD_HALF), 전방 강타** | "길 전체를 타격, 5초마다, 길·도시 파괴" 요청. 좌우 회피 불가 → 붕괴로 후퇴 압박 |
| 붕괴 = **collapseZ 경계 전진** (불 없음) | "불타는 연출 ❌" 요청. 무너진 길=어둡게 가라앉은 잔해+기운 건물. creep + 거대 운석 점프로 전진 |
| 거대 운석 착지 = **min(collapseZ+STEP, playerZ−SAFE)** | 플레이어보다 SAFE(7)보다 가깝게는 안 떨어져 즉사 방지. 가까우면 경계가 바짝 붙어 후퇴 강제 |
| 게임오버 = **운석 직격(1히트) 또는 붕괴에 닿음** | 1의 1히트 회피 + 붕괴 추락 두 가지 실패 |

## 코드 구조

```
meteor-game-2/
├── index.html
├── vite.config.js            base './' → /meteor2/, dev 포트 5274
├── tools/smoke.mjs           헤드리스 시뮬레이션 검증 (node로 실행)
├── src/
│   ├── main.js               부팅 + window.__meteorDash 디버그 훅
│   ├── game.js               씬·루프·붕괴 경계·거대 운석 타이머·콜백 와이어링
│   ├── constants.js          길/붕괴/거대 운석 튜닝 상수
│   ├── sfx.js                Web Audio 합성 (siren / bigImpact 포함)
│   ├── scenes/road.js        일직선 길 + 좌우 도시, 플레이어 추종 재활용 + 붕괴(잔해) 렌더
│   ├── objects/player.js     1과 동일(직접 이동·점프), 좌우만 길 폭으로 제한
│   ├── systems/camera.js     1과 동일 ChaseCamera(높이4·뒤14) + 흔들림
│   ├── systems/meteors.js    회피 운석(1 방식) + 거대 운석 상태머신
│   ├── systems/effects.js    폭발 파편/링/섬광/크레이터 풀 (1에서 재사용)
│   └── ui/
│       ├── joystick.js       가상 조이스틱 (1과 동일, 360°)
│       ├── jumpbutton.js     점프 버튼 (좌측 하단)
│       └── hud.js            TIME/SCORE + 음소거 + 게임오버(사유 표시)
```

워크플로우(`deploy-docs.yml`)가 자동으로 `meteor-game-2/`를 빌드해 `/meteor2/`로 배포.
