## 현재 상태

**프로토타입 v0.1.** Three.js + Vite, `/meteor2/` 경로로 자동 배포. 운석피하기1(`meteor-game/`)의 모듈 구조를 기반으로 **엔드리스 러너**로 재설계했다.

코어 루프 동작:

- **카메라 쪽(화면 아래)으로 도망** — 플레이어 앞모습이 보이고, 재앙은 화면 위(멀리=전방=-Z)에서 내려옴. 캐릭터 z=0 고정, 월드가 -Z로 스크롤. 조이스틱 좌우 조향, JUMP 수직 회피
- **길 + 좌우 도시가 끝없이 같은 패턴으로 재생성** (구획 16개 스크롤·재활용)
- 길 위로 **작은/중간 운석**이 쏟아짐 (그림자 1초 예고 → 낙하 → 폭발), 직격 시 게임오버
- **5초마다 거대 운석**이 화면 위(지나온 길)를 강타 → 대폭발·화면 흔들림·도시 붕괴 + 화염벽 전진
- **화염벽이 화면 위에서 플레이어를 향해 추격** (`lead` = 거리, 화염벽 z = -lead). lead ≤ 0이면 삼켜져 게임오버
- HUD: 질주 거리(m) + 시간 + 🔥 추격 위험도 게이지

비주얼은 절차적 박스/구체 + 단색 (에셋 파일 0).

### 헤드리스 검증

`meteor-game-2/tools/smoke.mjs` — 렌더러/DOM 없이 시뮬레이션 루프만 30초(1800프레임) 돌려 검증.

`cd meteor-game-2 && node tools/smoke.mjs` 로 재실행.

## 주요 결정 (왜 그렇게 했는지)

| 결정 | 이유 |
|------|------|
| 별도 디렉터리 `meteor-game-2/` | 운석피하기1을 보존하고 "2"로 분기. 워크플로가 `/meteor2/`로 별도 배포 |
| **엔드리스 러너 + 월드 스크롤** (캐릭터 z=0 고정) | 좌표 부동소수 누적 방지 + 카메라/화염벽 계산 단순화. 길 구획을 -Z로 밀고 카메라 뒤(+Z, NEAR_Z)에서 재활용 |
| 시점: **카메라 쪽(화면 아래)으로 도망, 재앙은 화면 위(-Z)** | 사용자 요청. 플레이어가 카메라를 향해(앞모습) 달려오고, 전방(-Z·멀리=화면 위)에서 거대 운석·화염벽이 내려옴. 카메라는 +Z·높은 곳에서 -Z를 내려다봄 — 시선이 여전히 -Z라 **조작 좌우 반전 없음** |
| 길 폭 = **26 (ROAD_WIDTH)** | "화면보다 살짝 넓게" 요청. 가장자리가 화면 밖으로 살짝 나가도록 |
| 거대 운석 = **고정 착지점 z=-16, 반지름=ROAD_HALF(13)** | 카메라(z=24)·플레이어(z=0)와 겹치지 않는 안전 구간. 화면 위(-Z)에 떨어져 지나온 길 강타. 구 앞면(z=-3)과 카메라(24) 거리 27>반지름13 → 관통 방지. 길 전체 폭(±13)을 덮음 |
| 파괴 = **화염벽 `lead` 모델** | "뒤쪽 도시가 파괴되고 계속 달려야" 요청을 거리 게이지로 구현. 거대 운석 강타가 화염벽을 끌어당김(surge) |
| 거대 운석은 **회피 대상 아님(화면 위 강타)** | 길 전체 폭이라 좌우 회피 불가 → "지나온 곳을 파괴하는 재앙"으로 배치. 직접 위협은 작은 운석(회피) + 화염벽(추격) |
| 작은 운석 = **1히트 게임오버** | 운석피하기1과 "동일한 게임형태" 유지 |
| 도시 붕괴 = **구획 단위로 그을림·기울임** | 화염벽 통과 시점에 per-segment 머티리얼/스케일 보간. 재활용으로 앞에 가면 리셋 |

## 코드 구조

```
meteor-game-2/
├── index.html
├── vite.config.js            base './' → /meteor2/ 어느 경로든 작동, dev 포트 5274
├── tools/smoke.mjs           헤드리스 시뮬레이션 검증 (node로 실행)
├── src/
│   ├── main.js               부팅 + window.__meteorDash 디버그 훅
│   ├── game.js               씬·라이팅·루프·거대 운석 타이머·콜백 와이어링
│   ├── constants.js          길/속도/화염벽/거대 운석 튜닝 상수 한곳 모음
│   ├── sfx.js                Web Audio 합성 (+ siren / bigImpact 추가)
│   ├── scenes/road.js        일직선 길 + 좌우 도시, 스크롤·재활용·파괴(붕괴) 연출
│   ├── objects/player.js     카메라 향해 질주(앞모습) + 좌우 조향(기울임) + 수직 점프
│   ├── systems/camera.js     ChaseCamera (앞 24·높이 14에서 -Z 내려다봄, 부분 X 추종, 흔들림)
│   ├── systems/meteors.js    작은 운석 풀 + 조준 스폰 + 거대 운석 상태머신
│   ├── systems/destruction.js 화염벽(lead) 추격 + 화염 비주얼 + danger 게이지
│   ├── systems/effects.js    폭발 파편/링/섬광/크레이터 풀 (1에서 재사용)
│   └── ui/
│       ├── joystick.js       가상 조이스틱 (x축 = 좌우 조향)
│       ├── jumpbutton.js     점프 버튼 (우측 하단, 쿨다운 sweep)
│       └── hud.js            거리(m)/시간 + 🔥 추격 위험도 게이지 + 게임오버
```

워크플로우(`deploy-docs.yml`)가 자동으로 `meteor-game-2/`를 빌드해 `/meteor2/`로 배포.
