# 운석피하기2 (Meteor Dash)

> 운석피하기1과 **똑같은 조작·카메라·시점**. 단, 무대가 **원형 경기장 → 일직선 길**로 바뀐다.
> 5초마다 길 전방(화면 안쪽)에 길 전체 폭을 때리는 **거대 운석**이 떨어져 길과 도시를 무너뜨린다.
> 무너진 길은 카메라 쪽으로 다가오므로, 자유롭게 움직이되 **계속 뒤로 물러나며** 작은 운석도 피해야 한다.

### 운석피하기1과 같은 점 ✅ (요청: "기본적으로 1과 동일")

- **동일한 카메라/구도** — 낮은 시점(높이 4)에서 뒤에서 화면 안쪽을 비춤, 하늘 넓게 가시, 캐릭터 화면 중상단
- **직접 360° 이동** (자동 달리기 ❌) — 가상 조이스틱으로 플레이어가 직접 조종
- **점프 회피 대시** (좌측 하단 버튼, 1초 쿨다운)
- **회피용 운석** — 그림자 예고 → 대각선 낙하 → 폭발, **직격 시 1히트 게임오버**
- 캐릭터 절차 애니메이션, Web Audio 사운드, 음소거 토글, TIME/SCORE HUD

### 운석피하기1과 달라진 점 🔁

- **맵: 원형 경기장 → 일직선 길** (좌우로 도시가 이어짐, 길 폭은 화면보다 살짝 넓게). 길/도시는 플레이어를 따라 **끝없이 같은 패턴으로 재생성**
- **5초마다 거대 운석** — 길 전방(화면 안쪽, 가까이서)에 길 전체 폭으로 강타. 빨강 예고 띠(1.3초) → 강하 → **대형 폭발**(길+좌우 도시까지) + 강한 화면 흔들림
- **불바다 글로우** — 폭발 지점에 **다음 폭발까지 붉은 불바다**가 감돌고(점광으로 주변도 붉게), 다음 거대 운석이 떨어지면 그 자리로 옮겨감
- **붕괴(파괴된 길)** — 거대 운석 지점부터 길이 무너지고(어둡게 가라앉은 잔해 + 위의 붉은 불바다), 그 경계가 플레이어 쪽으로 전진. 무너진 길에 닿으면 게임오버 → 자유 이동이지만 **앞이 막혀 카메라 쪽으로 후퇴**할 수밖에 없음
