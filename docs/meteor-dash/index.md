> 무너지는 도시의 일직선 길을 끝없이 질주하는 3D 엔드리스 러너.

### 운석피하기1과 달라진 점 🔁

| | 운석피하기1 | 운석피하기2 |
|---|---|---|
| 맵 | 원형 경기장 (자유 이동) | **일직선 길** (좌우로 도시가 이어짐, 화면보다 살짝 넓은 폭) |
| 이동 | 360° 자유 이동 | **자동 전진 + 좌우 조향** (엔드리스 러너) |
| 길 생성 | 고정 | **끝없이 같은 패턴으로 재생성** (구획 스크롤·재활용) |
| 핵심 위협 | 떨어지는 운석 회피 | 운석 회피 **+ 5초마다 거대 운석이 길 전체를 강타해 도시 파괴** |
| 추격 요소 | 없음 | **화염벽이 등 뒤에서 추격** — 거리(lead)를 0으로 만들면 삼켜짐 |

### 구현 완료 ✅

- **일직선 길 + 좌우 도시**: 구획(segment) 16개를 +Z로 스크롤시키고 카메라 뒤로 넘어가면 맨 앞으로 재배치하며 건물 높이/색을 다시 굴려 **끝없는 길** 생성
- **자동 질주**: 월드(길·도시)가 스크롤되고 캐릭터는 z=0 고정 → 좌우 조향 + 수직 점프만 조작. 질주 속도는 시간에 따라 가속
- **길 위로 쏟아지는 작은/중간 운석**: 그림자 1초 예고 → 낙하 → 지면 폭발. 캐릭터 위치 조준 스폰 포함. **직격 시 게임오버** (조향/점프로 회피)
- **거대 운석 (5초마다)**: 길 전체 폭을 덮는 크기. 빨강 예고 띠(1.4초) → 강하 → 길 뒤쪽에 강타 → **대폭발 + 화면 흔들림 + 도시·길 파괴** + 화염벽 전진(surge)
- **화염벽 추격(파괴)**: 플레이어와의 거리 `lead`로 표현. 달리면 회복(+물러남), 거대 운석 강타마다 확 다가옴. **lead ≤ 0 → 화염에 삼켜져 게임오버.** HUD 하단 🔥 게이지로 위험도 표시
- **파괴 연출**: 화염벽을 지난 구획은 길이 검게 그을리고 **건물이 기울며 무너진다**. 등 뒤 붉은 점광이 위험도에 따라 강해짐
- **캐릭터 절차 애니메이션** (질주 모션 + 조향 시 기울임 + 점프 만세 포즈)
- **Web Audio 사운드**: 경고 / 휘파람 / 폭발 / **거대 운석 사이렌·강타** / 발걸음 / 게임오버 / UI + 음소거 토글
- HUD: **질주 거리(m)** + 시간 + 🔥 추격 위험도 게이지, 게임오버 화면(사인 원인 표시) + 다시하기
