# 무기

부대원이 모두 동일 무기를 동시에 발사. 무기는 **무기 상자를 파괴**해 드롭된 아이템을 부대원이 주워서 교체됨.

---

## 발사 패턴

```
발사 빈도: 1000 / interval (발/초)
```

| 무기 | 발사 빈도 |
|------|-----------|
| 권총 | 초당 3.33발 |
| 기관단총 | 초당 6.67발 |
| 샷건 | 초당 1.67발 × 5탄 = 8.3탄 |
| 라이플 | 초당 2.86발 |
| 기관총 | 초당 10발 |

부대원 N명이면 총 발사 수 = 위 빈도 × N.  
보스 처치 강화로 **발사체 +1**을 선택하면 부대원 1인당 추가 1발 발사.  
강화로 **연사 +20%**를 누적 선택하면 실제 간격 = `max(40ms, 기본간격 × 연사배수)`.

## 무기 설계 의도

DPS만 보면 기관총이 압도적이지만, **DPS 단조증가는 아님**. 상황별 강점:

| 적 상황 | 추천 무기 | 이유 |
|---------|----------|------|
| 일반 좀비 대량 (1HP) | 기관총 / 기관단총 | 빠른 처리 |
| 무기 상자 파괴 | 라이플 (DMG 3) | 체력 높은 상자 효율적 제거 |
| 보스 | 기관총 / 라이플 | 높은 단일 DPS |
| 초반 | 권총 → 기관단총 순으로 교체 | 자연스러운 강화 흐름 |

무기 상자는 10초마다 중앙 3레인 중 랜덤 위치에 낙하하며 드롭 무기도 랜덤.  
상자의 무기 이름과 색상이 표시되므로 원하는 무기를 노려볼 수 있다.

---

## 무기 획득 방법

| 방법 | 설명 |
|------|------|
| **무기 상자 파괴** | 중앙 레인 낙하 상자를 총으로 깎아 파괴 → 랜덤 무기 드롭 |
| **드롭 아이템 픽업** | 낙하하는 무기 아이템(작은 원)에 부대원이 닿으면 즉시 교체 |

상세 내용은 [무기 상자 시스템](상자.md) 참조.

---

## 발사체 비주얼

모든 발사체는 반지름 5의 흰색 원에 **무기 컬러로 틴트**. 무기별 색을 일관되게 적용.
