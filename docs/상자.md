# 상자 시스템

화면 좌측 10% 영역에 정적 상자 4개가 슬롯에 쌓여있다. 부대원이 직접 들어가서 발사체로 상자를 공격하고, HP를 모두 깎으면 안에 든 무기 아이템이 떨어진다. 떨어진 아이템과 부대원이 닿으면 무기가 즉시 교체된다.

---

## 좌측 영역 슬롯 구성

화면 좌측 10% (x = 0 ~ 54)에 세로로 4개 슬롯. 발사체는 위로 직진하므로 **하단 슬롯부터 순차적으로 격파** 가능.

| 슬롯 | y 좌표 | 배치된 상자 | 비고 |
|------|--------|------------|------|
| 0 (최상단) | 110 | 군용 상자 | 가장 강함, 마지막 격파 |
| 1 | 230 | 강화 상자 |  |
| 2 | 350 | 철제 상자 |  |
| 3 (최하단) | 470 | 나무 상자 | 가장 약함, **첫 격파 가능** |

격파 후 5초 뒤 같은 종류의 상자가 같은 슬롯에 다시 등장.

---

## 상자 종류 (생성 순서대로)

생성 순서는 _가장 약한 → 가장 강한_ 순. 동시에 좌측 슬롯의 _하단 → 상단_ 순서와 일치.

| 생성 순서 | 상자명 | HP | 색상 | 안에 든 무기 |
|----------|-------|-----|------|-------------|
| 1 | **나무 상자** | 3 | 🟫 갈색 (`#a17c4c`) | 기관단총 (DMG 1, 150ms) |
| 2 | **철제 상자** | 8 | ⚪ 회색 (`#8a8a8a`) | 샷건 (DMG 1, 600ms × 5발 35°) |
| 3 | **강화 상자** | 15 | 🟦 진청 (`#4a4aa8`) | 라이플 (DMG 3, 350ms) |
| 4 | **군용 상자** | 25 | 🟩 군녹 (`#2a4a2a`) | 기관총 (DMG 2, 100ms) |

---

## 부대원 손익 계산 예시

권총(DMG 1, 400ms 간격) 부대원 1명 기준 격파 시간:

| 상자 | HP | 격파 소요 시간 |
|------|-----|---------------|
| 나무 | 3 | 1.2초 |
| 철제 | 8 | 3.2초 |
| 강화 | 15 | 6.0초 |
| 군용 | 25 | 10.0초 |

부대원이 늘어나면 발사 수 비례로 격파 시간 단축. 강한 무기 획득 후엔 더 강한 상자 격파 시간이 다시 짧아짐 → **자기강화 루프**.

---

## 권장 진행

1. 시작 위치(중앙)에서 **하단(나무 상자)으로 이동** → 권총으로 1초 만에 처치 → 기관단총 획득
2. 기관단총으로 **철제 상자 격파** → 샷건
3. 샷건으로 **강화 상자**(거리 짧고 5발 광역) → 라이플
4. 라이플(DMG 3)로 **군용 상자** 단숨에 격파 → 기관총
5. 사이사이 **우측 +1명 아이템** 챙겨 부대원 늘리기, 중앙 적 처치

---

## 무기 아이템 드롭

- 상자 처치 위치에서 작은 원형 아이템(무기 색상) 출현
- 화면 아래로 천천히 낙하 (70 px/s)
- 부대원과 닿으면 무기 즉시 교체 + HUD 강조 애니메이션
- 화면 밖으로 나가면 사라짐 (놓치면 다시 못 줍는다)

## 우측 +1명 아이템

- 우측 10% 영역에서 4.5초마다 자동 생성
- 동시 최대 3개까지만 화면에 존재
- 90 px/s로 낙하
- 부대원과 닿으면 부대원 +1
