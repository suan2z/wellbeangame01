## 현재 상태

플레이 가능한 프로토타입 **v0.3**. Phaser 3 웹 빌드, GitHub Pages 자동 배포.

- 스테이지 1부터 **무한 진행** (스테이지당 웨이브 = 4 + 스테이지)
- 무기 **10종 (T1~T10)** + 등급별 부대원 외형 변화
- 보스 5단계 외형 순환 + 5종 탄막 패턴
- 보스 처치 시 **강화 선택** (6종 중 3개)
- 사운드 (Web Audio 합성), 흐르는 배경 + 스테이지별 팔레트
- 적/보스 squash & stretch 애니메이션

## 주요 결정 (왜 그렇게 했는지)

| 결정 | 이유 |
|------|------|
| 엔진 = **Phaser 3 (웹)** | 로컬 엔진 설치 없이 Claude로만 진행 가능, 즉시 배포 |
| 이동 = **자유 좌표** | 3레인 스냅은 광고용, 실제 라스트워는 free 이동 |
| 부대 형태 = **해바라기 원형** | 일렬보다 시각적으로 살아있음 |
| 무기 획득 = **상자 파괴** | 게이트보다 능동 선택 + 킬 반경 위험 부담 |
| 적 속도 = **18 px/s**, 보스 30 후 정지 | 빠른 페이스는 정신없음, 반응 시간 확보 |
| 스테이지 클리어 = **무기·화력 버프만 리셋** | 점수·부대·이동/점수 버프 유지로 누적 보상감 |
| 흔들림 = **보스 처치만 유지** | 일반 적 처치마다 흔들리니 눈 피로 호소 |
| 영구 성장 = **제외** | 로그라이크 단발성 방향으로 결정 |
| 사운드 = **Web Audio 합성** | 에셋 파일 없이 오프라인 동작 |
| 무기 드롭 = **스테이지별 등급 캡** | 초반에 강력 무기 안 나오게 (maxTier = 2 + stage) |
