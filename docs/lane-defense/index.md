### 구현 완료 ✅

- 좌우 드래그 이동 + 자동 사격 (적 강하 18px/s)
- 일반 적 웨이브 (60ms 간격)
- **스테이지 / 웨이브 구조** (스테이지 1부터 무한, 스테이지당 웨이브 = 4 + 스테이지)
- 웨이브당 보스 1마리 + 5종 탄막 패턴 순환
- 스테이지 클리어 시 **무기·화력 버프 초기화** (점수·부대원·이동/점수 버프 유지)
- 보스 외형 5종 순환 + 스테이지/웨이브 비례 HP 증가
- 보스 처치 시 강화 선택 (6종 중 3개 제시)
- **무기 10종 (T1~T10)** + 등급별 부대원 외형 변화 + 무기 상자(3레인 낙하)
- 부대원 아이템 -1/+1/+2/? (좌우 랜덤 낙하)
- 스테이지별 배경 팔레트 + 처치 파티클 / 화면 흔들림
- 음향 효과 (Web Audio API, 에셋 파일 없음)
- 하이스코어 로컬 저장
